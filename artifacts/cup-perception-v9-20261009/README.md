直接检测杯筒下方露出的杯子（`exposed_cup`）。没有封口机配准、固定坐标回退、旧机械臂标定依赖。
本目录发布任务一 v9 候选模型，保留仓库的 v7 和任务二，不会自动更新另一台电脑。

## 实测结果（默认阈值 0.30）

20 轮后早停，使用开发验证选中的第 5 轮权重；没有根据保留测试结果更换权重或调整阈值。
“唯一正确检出”要求框与人工标注 IoU≥0.5，并且没有额外候选框。

| 样本组 | v7 当前（.05） | v8 实验（.225） | v9 补充微调（.30） |
|---|---:|---:|---:|
| 旧 50 张原图回归 | 50/50 | 49/50 | 50/50 |
| 新 19 张原图回放（含训练图） | 16/19 | 19/19 | 19/19 |
| 新保留测试原图 | 3/4 | 4/4 | 4/4 |
| 新保留图的 48 次变换测试 | 30/48 | 48/48 | 46/48 |
| 旧倾斜图的 60 次已知场景回归 | 52/60 | 58/60 | 60/60 |
| 72 张合成负样本出现检测的张数 | 0 | 1 | 0 |

新保留 4 张测试图的平均最佳框 IoU 为 .812，匹配框置信度中位数 .815；分数不等于正确率。
新增 19 张的全部回放平均 IoU 为 .845，但其中包含参与训练和选权重的图片。

改进：旧 `0049` 的重复框、旧倾斜变换中的重复框/漏检在本轮回归中消失；新原图回放没有漏检或额外框。
仍有局限：`new_0016_scale_0.65`、`new_0018_scale_0.65` 两张缩小目标测试漏检，v8 在这两项反而通过。
因此 v9 不是所有条件下都更优；特别远、小的杯子仍需现场观察，不能宣称任意角度稳定。
这些是离线小样本结果，仍没有真实空工位负样本和独立现场长时间运行验证。

14 项数据/接口测试通过，PT 与 ONNX 在 69 张原图的输出一致性检查全部通过。
本机 v7、v8 和任务二权重未改变；此 GitHub 发布只增加 v9，尚未部署到观测电脑。

## 文件和验证

- `supplement-audit.json` / `supplement-label-review.jpg`：新增标签审计及完整画幅预览。
- `annotation-audit.json`：69 张来源、校验值、划分、初始化模型记录。
- `prepare.py` / `train.py`：数据准备与微调。
- `calibrate.py`：训练派生图选择阈值；没有人为放大分数。
- `compare.py`：比较 v7 当前、v7 末期、v8、v9；保留漏检及重复框记录。
- `export_model.py` / `verify_export.py`：ONNX 导出及 69 张图的输出一致性检查。
- `test_dataset.py` / `test_runtime.py`：来源隔离、变换坐标、多候选保护等检查。

## 单图识别

```bash
cd artifacts/cup-perception-v9-20261009
python recognize.py \
  /绝对路径/原始图片.jpg --output /绝对路径/识别预览.jpg \
  --json-output /绝对路径/识别结果.json
```

保持 `recognize.py`、`runtime-config.json`、`weights/` 为同一套版本，默认从配置读取校准阈值。
默认 CPU 推理；不打开摄像头、不启动机器人。输出路径不要指向输入图片。
只有唯一检测候选才提供二维框中心；多候选/漏检时不沿用上一帧坐标。
单图不会被标为时序稳定；实时调用方可显式使用 `StabilityGate`。
二维框中心不是测量到的杯底点，也不是三维抓取坐标；`robot_motion_ready` 保持 false。

## 复现顺序

识别入口只依赖本目录的代码、配置和权重；安装 `requirements.txt` 中的依赖后可运行。

训练/审计脚本保留本机实验路径，**不是下载仓库即可完整重训**：原始 69 张图片、两个原始标签 ZIP、
v8 初始化权重及其 `annotation-audit.json` 未随本次发布上传。
需要自行准备这些输入并调整脚本中的路径；`test_dataset.py` 也需要本机生成的数据目录。
`test_runtime.py` 可直接运行，不需要原始数据或连接摄像头。
在具有上述训练输入的新输出目录中执行：

```bash
python inspect_supplement.py
python prepare.py
python -m unittest test_dataset test_runtime -v
python train.py
python export_model.py
python calibrate.py
python compare.py
python verify_export.py
```

已存在的数据目录和已打包权重不会被准备/导出脚本静默覆盖。
